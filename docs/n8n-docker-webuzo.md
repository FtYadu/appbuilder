# Deploying n8n with Docker and Webuzo

This guide covers setting up an n8n instance on a server managed by Webuzo. It follows a one-shot provisioning script that prepares Docker, PostgreSQL, and n8n, then explains how to expose the service securely.

## 1. Run the provisioning script

The repository now includes an executable helper, `scripts/deploy_n8n.sh`, that provisions Docker, PostgreSQL, and n8n with a single command. Provide your domain and subdomain and it will generate the `.env`, `docker-compose.yml`, and health-check the stack automatically.

```bash
./scripts/deploy_n8n.sh --domain ftyadu.in --subdomain n8n
```

By default the script installs to `/opt/n8n`, sets the timezone to `Asia/Dubai`, and waits for n8n to listen on `127.0.0.1:5678`. Use `--app-dir`, `--timezone`, `--force`, or `--skip-health-check` to customise the deployment. Re-running the script preserves the existing encryption key and database password unless `--force` is supplied.

> **Tip:** run `./scripts/deploy_n8n.sh --help` to review the full option set and confirm that Docker, Docker Compose v2, `curl`, and `openssl` are available before starting the deployment.

## 2. Configure Webuzo for public access

1. **DNS:** add an `A` record for `n8n.ftyadu.in` pointing to your server.
2. **SSL:** issue a Let’s Encrypt certificate for the subdomain in Webuzo.
3. **Reverse proxy:** forward HTTPS traffic to the internal n8n port `127.0.0.1:5678`.

If you can edit the Nginx include file for the subdomain, use the following snippet:

```nginx
server {
  listen 443 ssl http2;
  server_name n8n.ftyadu.in;

  # SSL is handled by Webuzo panel's generated directives
  include /usr/local/apps/nginx/conf/ssl/n8n.ftyadu.in/*.conf;

  location / {
    proxy_pass http://127.0.0.1:5678/;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto https;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
  }
}
```

Reload Nginx or Apache from the Webuzo UI when finished. The first user to sign up in n8n will become the instance owner.

## 3. Environment reference

These values populate the `.env` file and should be updated if you change domains:

- `N8N_HOST=n8n.ftyadu.in`
- `N8N_PORT=5678`
- `N8N_PROTOCOL=https`
- `WEBHOOK_URL=https://n8n.ftyadu.in/`
- `N8N_EDITOR_BASE_URL=https://n8n.ftyadu.in/`
- `N8N_SECURE_COOKIE=true`
- `N8N_ENCRYPTION_KEY=<auto-generated 48+ char key>`
- `TZ=Asia/Dubai`
- `DB_TYPE=postgresdb`
- `DB_POSTGRESDB_HOST=postgres`
- `DB_POSTGRESDB_PORT=5432`
- `DB_POSTGRESDB_DATABASE=n8n`
- `DB_POSTGRESDB_USER=n8n`
- `DB_POSTGRESDB_PASSWORD=<auto-generated>`

After any domain change, update `.env` and restart n8n:

```bash
cd /opt/n8n
docker compose restart n8n
```

## 4. Maintenance tips

- **Update n8n:**
  ```bash
  cd /opt/n8n
  docker compose pull && docker compose up -d
  ```
- **Back up the database:**
  ```bash
  docker exec -t $(docker compose ps -q postgres) \
    pg_dump -U n8n n8n > /opt/n8n/backup_$(date +%F).sql
  ```
- **Tail logs:**
  ```bash
  docker compose logs -f n8n
  ```

## 5. Optional path deployment

To serve n8n at `https://ftyadu.in/n8n`, update the environment file:

```
N8N_HOST=ftyadu.in
N8N_PROTOCOL=https
WEBHOOK_URL=https://ftyadu.in/n8n/
N8N_EDITOR_BASE_URL=https://ftyadu.in/n8n/
```

Then adjust the Nginx configuration:

```nginx
location /n8n/ {
  proxy_pass http://127.0.0.1:5678/;
  proxy_set_header Host $host;
  proxy_set_header X-Forwarded-Proto https;
  proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
  proxy_http_version 1.1;
  proxy_set_header Upgrade $http_upgrade;
  proxy_set_header Connection "upgrade";
  sub_filter_once off;
  sub_filter 'href="/' 'href="/n8n/';
  sub_filter 'src="/'  'src="/n8n/';
}
```

Restart the reverse proxy and run `docker compose restart n8n` to apply the path-based configuration.
